# UI style (locked)

Chosen by the user on 2026-11-10 and shared with the ElderScroll tools hub:

- **Glassmorphism** cards: translucent white wash, lit top-left edge, rounded 18 px.
- **Moonsilver** background: dark silver diagonal gradient with soft moonlight glows (top-left and bottom-right).
- Buttons: **brushed metal**, two variants - `silver` (primary action) and `black` (secondary action), engraved text, drop shadow.
- 3D scene: silver-metal and black-metal materials; white chess pieces are silver, black pieces are black.
- Code: `Python/ui/theme.py` (palette + style sheet), `Python/ui/glass_widgets.py` (background, card, button).
